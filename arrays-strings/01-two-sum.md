# Problem: Two Sum (Easy)

**Link:** https://leetcode.com/problems/two-sum/

### Approach

The goal is to find two numbers in the array whose sum is equal to the target. I used two nested loops to compare each pair of elements and check whether their sum matches the target.

### Complexity

- Time: O(n²)
- Space: O(1)

### Notes

The same element should not be used twice. I used different indices for each pair to avoid using the same element.
