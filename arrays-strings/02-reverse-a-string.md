# Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used a simple loop to reverse the string. I first find the length of the string using `strlen()`. Then I start from the last character and print each character in reverse order.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The string is reversed by accessing its characters from the last position to the first position.
